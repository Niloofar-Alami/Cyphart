# Cyphart

A sleek, cyberpunk-inspired dashboard built with pure HTML and CSS. I created this project to practice advanced layout techniques (like Grid and Flexbox) and to wrap up my HTML & CSS learning journey.

## Features
- Clean dark-mode cyberpunk UI
- Interactive node selection using pure CSS (no JavaScript)
- Simulated real-time terminal logs and metrics
- Fully responsive design

## Tech Stack
- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Google Fonts (JetBrains Mono & Syne)

## How to Run
Just clone the repository and open `index.html` in your browser!
